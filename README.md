# 📻 NovaRadio - Modern Internet Radio PWA

> **Live Web App & PWA**: Luister naar meer dan 40.000 live radiostations wereldwijd met Chromecast-ondersteuning, favorietenbeheer en lock screen controls voor smartphones en Android Auto / Apple CarPlay.

---

## ✨ Functies

- 🌟 **Startscherm met Favorieten**: Direct toegang tot je favoriete Vlaamse, Nederlandse en internationale zenders.
- 🌍 **Zendergids (40.000+ zenders)**: Bladeren en realtime zoeken via de open Radio Browser API op land, genre of zendernaam.
- 📡 **Google Cast (Chromecast & Google Nest)**: Stream naadloos naar je Chromecast of slimme speakers met één klik op het Cast-icoon.
- 📱 **Progressive Web App (PWA)**: Installeerbaar op iPhone en Android met offline caching en fullscreen app-ervaring.
- 🚗 **Android Auto & CarPlay Gereed**: Volledige integratie met de Media Session API voor stuurbediening en dashboardweergave in de auto.
- 🎨 **Modern Dark Glassmorphism Design**: Responsieve interface met dynamische spectrumvisualizer en mobielvriendelijke 2-rijen zoekbalk.
- ⏰ **Slaaptimer & Eigen Streams**: Stel een sleeptimer in (15, 30, 60 min) of voeg je eigen MP3/AAC streams toe.

---

## 🚀 Lokaal Draaien

NovaRadio vereist geen zware dependencies:

```bash
# Clone de repository
git clone https://github.com/yogibearke/novaradio.git
cd novaradio

# Start de lokale server
npm start
# of: node server.js
```

Open [http://localhost:3000](http://localhost:3000) in je browser.
